Train GraphRAG Community Index NEW
What is GraphRAG? Unlike HippoRAG's triple-extraction + PPR approach, GraphRAG builds a community index: entities are extracted from each passage, grouped into thematic clusters by a community-detection algorithm (Leiden/Louvain), and each cluster is summarised by the LLM. At query time, the most relevant community summaries are retrieved instead of raw passages. The index is saved as base.pkl alongside graph.pkl in the same model directory.
