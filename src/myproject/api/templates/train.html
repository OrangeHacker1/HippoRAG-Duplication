Train a New Knowledge Graph

Each non-blank line is treated as one document (one passage). The KG builder will extract triples from each passage via the LLM.

Enter the absolute path to a JSON file that already exists inside the Docker container. Supported formats:

1. Array of strings: ["doc1", "doc2"]

2. Array of objects: [{"title":"...","text":"..."}]

This becomes the folder name inside the kg_data Docker volume. Use a simple slug (letters, numbers, underscores, hyphens). The model named latest is the default loaded by the grader shortcut.

Load a Saved Knowledge Graph

These models are saved on the kg_data Docker volume and persist across docker compose down/up. Loading hot-swaps the active KG without restarting the server.

Tip for graders: To skip this manual step, set active_model: <name> in config/config.yaml and the app will load the model automatically on startup.
